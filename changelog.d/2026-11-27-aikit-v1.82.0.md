- **aikit pin is v1.82.0** in every goinfer module that requires it (the root, `backend/cuda`, `backend/metal`, `backend/webgpu` and
  `demo/agent`), from v1.78.0. v1.79.0 adds `MatmulQKAcc64F16` and `MatmulAVAcc64F16` (the 16-key QK kernel and its stride guard).
  v1.80.0 reworks the `linalg` surface: names moved or were removed, so a program that imports `aikit/linalg` beside goinfer builds
  against the new names; goinfer's recorded kernel fingerprints did not change. v1.81.0 adds `GGUFFile.ReleaseTensors` and
  `TensorBytes`, and v1.82.0 makes `ReleaseTensors` drop each converted tensor's bytes from the page cache, so a direct `.gguf` build
  of a file larger than free memory no longer fills the page cache with the source while it allocates the converted weights.
