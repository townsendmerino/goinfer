    What's different

    Each of these has a writeup: the problem, what goinfer does, what was measured, and what it doesn't do.

    All twelve →
    Control

    Stop means stop

    Cancel one generation by id, or halt everything from an HTTP call, a file, or a signal. Control lives on its own socket, away from the API.

    It doesn't sandbox what an agent does with the text it already received.

    Read →
    Structured output

    How sure was it?

    Each enum, boolean and integer field comes back with the model's probability over the answers the schema allowed. Useful for "ask a person below 0.7".

    It isn't the probability the answer is right. It is not calibrated.

    Read →
    Agents

    Tool calls that can't come out malformed

    When a model starts a tool call, one grammar covering every tool it was given keeps the call well-formed.

    It doesn't choose the right tool for the model. Llama 3 is left unconstrained.

    Read →
    Correctness

    Checked against the reference

    Every model family is tested against HuggingFace's own implementation, and the result is published beside it.

    It doesn't cover every quantization on every machine. A run names what it tested.

    Read →
    Memory

    It refuses rather than swaps

    If a model won't fit, goinfer says so and by how much, before your laptop grinds to a halt.

    It can't always hold the machine on its own. The swap tripwire notices in time, and the limit is written down.

    Read →
    Distribution

    One file, model inside

    A single binary with the weights compiled in. First token in about half a second, 77 MB resident.

    It isn't small. The 0.5B build is around 600 MB.

    Read →

    What didn't work

    Ideas measured against a target set in advance, and dropped when they missed it. They stay published.

    Dropped

    Prefix-aware scheduling

    1.024×

    Needed 1.15× to stay. Reverted the same day it was built.

    Removed

    Adaptive speculation width

    0 of 4

    ship gates passed, so it was removed, as the plan written before the test said it would be.

    Refuted

    Quantizing the KV cache for speed

    no gain

    Smaller, not faster. Kept as a memory option only.
