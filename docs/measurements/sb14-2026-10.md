## 1. What it is

Two tests in `internal/layout`, beside SB13's:

- **`TestPackageDocs_namedTestsExist`** reads every package doc comment in the tree, `doc.go` or not: 77 today, 21 of
  their test names.
  - Every test a doc names must exist where the prose puts it. "decoder's TestX" means package `decoder` (the
    possessive may end the line before the name). A name inside a `go test ./pkg … -run` command means that command's
    package. A bare name means the doc's own package.
  - Every line of an "Invariants" block must name a test.
- **`TestArchitecture_importAppendix`** checks `docs/ARCHITECTURE.md`'s import appendix, which is generated from SB13's
  `internal/layout/imports.json`: a row per importing package with its imports and its test-only imports, then the
  protected rules.
  - It fails when the appendix differs from the data. `-update` regenerates it, the same flag that rewrites SB13's
    arrows.

**Drift found and fixed on the way:**

- **The Packages table.** `docs/ARCHITECTURE.md`'s hand-kept "Imports beyond stdlib" column still listed `aikit/gpu`
  for the CUDA and Metal backends, which AX3 removed. The table now keeps the purposes and points at the generated
  appendix, so the file has one import table.
- **The parity manifest.** The document named `testdata/parity_manifest.json` twice, a file VK3 removed; both now name
  the parity records.
- **A test named in prose the rule can't read.** `internal/paritykey`'s doc wrote "TestParityKey_matchesFreshDepsHash
  (decoder)". It now says "decoder's".
