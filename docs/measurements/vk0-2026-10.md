**What the replay is.** `replay.go` carries `decoder/parity_manifest_test.go:freshDepsHash`, `goCodeTokens`,
`familyDepFiles` and `aikitVersionRE` verbatim, and feeds them each commit's own manifest (sets, `uses`, `own`), its own
dependency files and its own root `go.mod`, read with `git cat-file` rather than from a working tree. Each commit is
hashed twice: with today's function (Go files as their token stream, since `5ff89161` on 2026-10-13) and with the
function of the day (raw bytes before `5ff89161`; the commit's own `parity_manifest_test.go` says which).

**What counts as a re-staling.** A family is re-staled by a commit when its hash there differs from its hash at every
parent. A merge that carries one side's validated state forward re-stales nothing; a merge whose combination neither
side held re-stales what it reaches. Walking only the first-parent chain was tried first and dropped: branches that
merged main and were then fast-forwarded make origin/main's first-parent chain run through eight days of one branch's
history (`2762ec03` to `999763c6`), so it is not the sequence of main's tips.

**Triggers** are the inputs of today's hash that differ from the first parent, over the families the commit re-stales:
a shared set's file, a family's `own` file, the aikit pin, or a change to the family's file list.

## 5. The before number

**In 30 days, today's key re-staled 8,895 family validations in 234 commits and made someone run 212 refreshes.
8,775 of those re-stalings (98.7%), in 228 commits, came with no moved golden and no changed recorded metric.**

That 98.7% is an upper bound on what a behavior key would not have re-staled, not the number itself:

- The goldens are tolerance tests on tiny fixtures, so "no golden moved" means "inside the goldens' bands", not
  "bit-identical". A key built from bit fingerprints re-stales on any bit change, including one the goldens absorb, so
  it re-stales more than these six commits.
- The exact count needs the fingerprints themselves at each commit: VK1's kernel fingerprint for the 46 aikit-pin
  commits, VK4's program fingerprint for the edits to `core`. For the aikit pin, VK1's record reads its fingerprint at
  the pinned versions it can build against.
- The largest single input is `decoder/model.go`: the sole trigger of 67 commits and 2,715 re-stalings. VK2 moves it
  out of `core`.
