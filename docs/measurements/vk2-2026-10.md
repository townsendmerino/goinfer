## 3. Found while planning part 2: the key does not cover the forward it validates

Part 2 is to move `decoder/model.go`'s numeric code into a file in `core` and take `model.go` out. To decide what
"numeric" meant, [`forwardreach`](vk2-2026-10/testdata/forwardreach/main.go) built a type-checked call graph from
`model.go`'s forward entry points (`forward`, `forwardFromEmbed`, `forwardCapture`, `runLayers`, `logitsFromHidden`).
It does not follow calls through interfaces or func values, so it undercounts.

**19 of the 38 files it reaches are in no hash set and no family's `own` list**
([`forward-reach-2026-10-26.txt`](vk2-2026-10/forward-reach-2026-10-26.txt)). Among them:

- `program.go` and `program_cpu.go` (33 functions: the program walker the forward now runs through)
- `fusedattn.go`, `cpu_gateup_fused.go` (the CPU fused gate+up+SwiGLU), `scratch.go`, `kda.go` and `kda_rehearsal.go`
- `forward_gemma4_moe.go`, `mla_int8.go`, `moepool.go`, `int4_floatact.go`, `kvdequant_parallel.go`, `layerpaging.go`,
  `lora.go`, `knobs.go`, `backend.go` and `routercapture.go`

An edit to one of them re-stales no family unless the same commit happens to touch a covered file:

- **42** non-merge commits in 30 days touched one of the 19 files.
- **36** of them re-staled anyway because they touched a covered file too; for **5**, `model.go` was the only covered
  file they touched.
- **6** re-staled nothing. Two were comment-only (CC4); the others were an error path in `program_cpu.go` (`fd63b067`),
  a measurement harness in `mla_int8.go`, counters in `cpu_gateup_fused.go`, and a void rule in `scratch.go`. None of
  the six is a missed numeric change, but nothing in the key would have caught one.

Taking `model.go` out of `core` as §5.5 says would make those 5 commits silent too, 11 in 30 days in all. Adding the
19 files to `core`, or to the `own` list of the one family that reaches them, would turn those 11 into re-stalings:
about 11 more re-staling commits in 30 days, against the 234 in VK0, before VK4's program fingerprint replaces source
keys. This is a decision for Francis, put in the session's report. Part 2 waits on it.
