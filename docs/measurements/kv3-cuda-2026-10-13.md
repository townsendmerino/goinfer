## 1. The Claude Code attribution header (done; merged on its own)

`goinfer-serve connect claude-code` now writes `CLAUDE_CODE_ATTRIBUTION_HEADER=0` into the `env` block of the settings file it
generates, and `docs/integrations/claude-code.md` says why in one sentence. The server does not rewrite the line.

**Gate: two Claude Code conversations through the KV0 traffic proxy with the generated config share their preamble.** Run by
`kv0-traffic-2026-10/header_gate.py`: a running server (Qwen2.5-Coder-0.5B, `-ctx 32768`), the settings written by
`serve connect claude-code -write`, `kv0_proxy.py` between Claude Code and the server, two different first prompts, Claude Code
2.1.296 unsandboxed in a fixed HOME and a fixed non-repository directory (as KV0's header probe ran). Bodies rendered with Qwen3's
tokenizer and template (`internal/serveapp/kv0_tokenize_test.go`).

| | request sizes (tokens) | common prefix |
|---|---|---|
| the generated config (header off) | 17,573 and 17,571 | **15,623** (88.9%): every token before the user's own text |
| the same config with the variable removed (control) | 17,602 and 17,600 | **22** |

- **The registered threshold, "18,000 or more", is not met, and cannot be in this configuration**: the whole request is 17.6k
  tokens. KV0's 18,213 was measured on a 20,154-token request. A bisect of Claude Code's environment shows the difference is
  how Claude Code is configured, not the header: through a settings file with `ANTHROPIC_AUTH_TOKEN` its first request is
  17,728 tokens, and through process environment variables with `ANTHROPIC_API_KEY` it was 20,189 (header on in both). The
  header variable removes 29 tokens and `CLAUDE_CODE_MAX_CONTEXT_TOKENS` 26 of them; the rest (about 2.5k) is the settings-file route's. What the gate is
  for holds: with the setting, conversations share everything that precedes the user's text (15,623 of 17,573); without it, 22.
- A first gate run with `run_cell.py` sessions shared 15,564 and diverged at `Recent commits:`: each session's fixture is a fresh git
  repository and its first commit's hash carries the clock. `kv0_run_cell.py` now pins the commit dates, so the hash is a
  function of the tree, as it is between conversations in one real repository.
