## Two recorder defects, found by the grade (fixed for the next run; this night corrected by hand)

1. **A false pass in the answer check.** When a harness's own reply was empty, `run_cell.py` graded the last 2,000 characters of its raw
   output instead. That text holds session ids and tool output. opencode x Qwen3-4B `read` r1 found no files, gave no answer, and
   passed because a `5` stood alone inside an id. It is graded **fail** below. It is the only answer-graded pass with an empty
   reply. The fallback is removed; replayed on that run's stdout, the old rule passes it and the new one fails it.
2. **No prompt sizes on `/v1/messages`.** A Messages stream carries `input_tokens` only in `message_start`, and `wire_proxy.py` read usage
   from the last 6,000 characters. Every Claude Code request has `prompt_tokens: null`. As a result, `gate_i1.py`'s incurable-jump test
   could not run for Claude Code: with no fixed part known, it is skipped without a warning. The proxy now falls back to the head of
   the body, which a fake stream with `message_start` outside the tail confirms (the pinned proxy records only `output_tokens`). For
   this night the sizes were read from the serve log (`-log-requests`).

  answered any overflow, and the overflow was followed by one compaction. At 28,672 the room beside Claude Code's fixed part holds
