# R-06 on arm64: the re-measure (2026-10-25)

Francis's word of 9:30 am, on the parked-gains audit (`docs/measurements/parked-gains-audit-2026-10-25.md`): remeasure R-06 on the
Mac. R-06 (`decoder/weightmat.go:w4a8BatchEnabled`, `GOINFER_W4A8_BATCH`) runs a layer's W4A8 q/k/v, and gate/up where the fused
gate+up does not take them, as one fork/join in CPU decode. It is bit-identical. It is on by default on non-arm64 since 2026-09-27,
and off on arm64 (`decoder/cpu_tuning_arm64.go:w4a8BatchDefault`) until measured on the current tree: the Mac read 1.071× on the 1.5B
in September and a null on the 7B (`docs/measurements/w4a8-batch-7b-2026-09-20.md`). On arm64 the batch op carries the row4
weights the Mac decodes from (`decoder/weightmat.go:wmW4A8Op`), so the change is live there.

## Registration (before any reading)

**Instrument:** `TestR06_speed` (`decoder/r06_arm64_test.go`), at fresh `origin/main`, `.gguf` checkpoints from `~/models`, CPU
backend, int4 (W4A8).
- **Models:** qwen2.5-coder 0.5B and 1.5B and qwen2.5 7B, Q4_K_M, each in its own process run.
- **Pairs:** on against off in one process per model, A B B A over 10 valid pairs after a warm-up. Each arm is 96 greedy tokens at
  depth 128, timed by the decoder's forward clock (ms a token).
- **Bit-identity:** every arm's token stream must equal the reference. `TestCPURoofline_w4a8Batch_logitsBitIdentical` (48 steps,
  every logit, all three models) runs first.
- **The void rule, adapted to CPU decode.** The run keeps the cores busy itself, so the busy-core line (half the cores) would void
  every arm. An arm is void when **other** processes' CPU averaged over it exceeds **1.0 core**: the machine's busy cores (`hostmem.ReadCPU`)
  less this process's own CPU time (`getrusage`). It is also void when reclaimable memory is under 2 GiB at either end. Before each
  load, reclaimable must cover the checkpoint plus 2 GiB. A void pair is re-run, up to 10 times a model.
- **Lock:** the timing lock, exclusive, with no other timed gate running. If the owner's apps leave memory short by day, the run
  goes to the Mac's night runner.

**Outcomes, per model, graded against the merge rule of 2026-10-25** (median ≥ 1.05× with at least 9 of 10 pairs faster):
- **Meets it:** consistently faster.
- **Below it, at least 9 of 10 faster:** a real but small gain. It is still not a merge-rule pass.
- **Below it, fewer than 9 of 10:** no consistent gain.
- **Any stream difference:** a defect. The run stops, and nothing is graded.

**What each overall outcome means for the default.** The default is per architecture, so turning it on for arm64 turns it on for
every model. That is a default change, so the grades go to Francis and the code does not change here.
- **All three meet the rule:** recommend on by default for arm64.
- **Some meet it:** recommend on only if the others read no slower. Otherwise a per-model default needs a size rule, which is
  Francis's call.
- **None meet it:** it stays off. `=1` remains the opt-in.

**Memory:** none added. R-06 batches three existing projections into one fork/join over their own weights and destinations, with
no new buffer.
