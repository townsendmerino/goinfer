# SB13: the package layout as data and a test — 2026-10-26

The record for SB13 ([`docs/tasks/task-subsystems-2026-10.md`](../tasks/task-subsystems-2026-10.md) §8 and §9),
graded against gates L1–L3, registered there before the code. Tier 0: imports are read by parsing, in about 0.2 s,
across every module. Measured on the MacBook at goinfer main `8c5fe261` plus this branch.

## 1. What it is

- **`internal/layout/imports.json`**, the data:
  - **`arrows` and `test_arrows`**: every import from one goinfer package to another, by repository-relative
    directory, from non-test and from test files. Today: 167 and 132.
  - **`rules`**: the protected separations, five of them, each with the reason in its own words (table below).
  - SB14's drift test and `docs/ARCHITECTURE.md`'s import table can read the same file.
- **`TestLayout_arrows`**, the test. It fails on:
  - an arrow the tree makes that the data lacks, named with the file that makes it;
  - an arrow the data records that the tree no longer makes;
  - any import, made or recorded, that breaks a rule;
  - a rule that names a package the tree does not have, since a rule that matches nothing checks nothing.

  `-update` rewrites the arrows from the tree and never the rules, and the rules are checked before it writes, so it
  cannot record a forbidden arrow.
- **nobara-sb01's `decoderRatchet`** (`TestBackendTests_decoderImportsOnlyFall`), in the same package, is untouched. It
  still counts the backend test files that reach `decoder`.

| rule | from | holds |
|---|---|---|
| towers-standalone | `internal/vision`, `internal/audio` | no goinfer import; outside the standard library only aikit's `linalg` and `embed` |
| gpudev-standalone | `cuda/internal/gpudev`, `metal/internal/gpudev` | no goinfer import |
| kernels-free-of-decoder | `cuda/kernels`, `metal/kernels` | no `decoder` import, in tests either |
| probe-standalone | `internal/mem/probe` | no goinfer import (that it is the only OS memory reader stays MM0's `TestOnlyProbeReadsOSMemory`) |
| root-free-of-backends | every root-module package | no import of the `cuda`, `metal` or `gpu` modules, aikit's GPU modules, purego or gocudrv; the root `go.mod` requires none of them |

Every rule holds the package's test files as well as its non-test files.
