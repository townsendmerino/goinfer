# aikit v1.70.1 → v1.70.2: destination-length audit (2026-10-15)

<!-- citations-at: d795053c -->

aikit v1.70.2 makes `linalg.DequantizeRowInt8` check `len(dst) >= len(q)`, and `WeightMat.Row` check `len(dst) >= cols`,
in every build, and panic on a short destination. Before, the int8 widen (AVX2/NEON) wrote `len(q)` floats through
`&dst[0]` with its only check behind `-tags aikit_checks`. The `Row` check sits before the layout switch, so it applies to
every kind, not only int8: an f32 `Row` into a short `dst` used to `copy` a silent prefix and now panics too. A caller
that sizes `dst` from the table's own width sees no change.

This record establishes, before the bump, that no goinfer caller can pass a short destination. aikit's own tree at
v1.70.2 has no other caller of either function (`DequantizeRowInt8` is reached only from `WeightMat.Row`), so the
goinfer call sites below are the whole exposure.

## Verdict: no call site can be short. Bump.

52 direct call sites across the five modules that require aikit (root `decoder`, `cuda`, `metal`; `gpu` and
`demo/agent` have none): 28 non-test (27 `Row`, 1 `DequantizeRowInt8`) and 24 in tests. Every destination is either
allocated at the table's own column width or is a slice of exactly that width. No call sizes `dst` from a different
dimension (head_dim, a Gemma 4 per-layer width, an MLA latent, a pooled buffer of another shape).

## Why the table widths are what the callers assume

The callers size from `Architecture.HiddenDim` (or the PLE total, or a drafter's own hidden). That is safe only if
each table's column count is that same number on every load path. It is:

| table | cols | enforced at load by |
|---|---|---|
| `Embed`, untied `LMHead` | `HiddenDim` | safetensors: `loadEmbedTable` / `loadMat` pass `[vocab, hidden]` to `TensorF32` or check the shape directly (the hidden comes from `arch.HiddenDim`, which `resolveArchitecture` copies from `cfg.HiddenDim`); GGUF: `buildWeightsFromGGUF`'s `embMat` checks `dims == [hidden, vocab]`; `.giw`: `validateShapes`' `cols("Embed", …, arch.HiddenDim)` |
| `PosEmbed` (gpt-2) | `HiddenDim` | `loadMat(st, "wpe.weight", MaxPositions, hidden)`; `.giw` `cols("PosEmbed", …)` |
| `PerLayerTokenEmbed` (Gemma 4 E) | `NumLayers × HiddenSizePerLayerInput` | safetensors shape check `[pleVocab, pleTotal]`; GGUF `embMat(…, pleTotal)`; `.giw` `cols("PerLayerTokenEmbed", …, pleTotal)` |
| DFlash / DSpark `embed` | drafter `hidden` | `loadMat(…, VocabSize, h)` |
| DSpark `markovW1` | `MarkovRank` | `loadMat(…, VocabSize, MarkovRank)`, loaded only when `MarkovRank > 0` |
| gpt-oss expert `Gate` | `HiddenDim` | `streamQ(expInter, hidden, …)` |

- decoder: `TestGemma4RunLayersFromEmbed_matchesTokenPath`, `TestGemma4EModel_residentEmbedRow` (`make(HiddenDim)`);

  `testPrefillParityMoEFixture`, `TestPrefillParityGemma`, `TestGemma2Softcap_lanesAndPrefillMetal`, `mc3Emb` (each
  `make(r.H)`), `prodEmbedRow` (callers `make(H)` / `make(r.H)`); metal/kernels `TestQ4KLaneKernels` (`make(K)`).

Method: `grep` for `DequantizeRowInt8` and `.Row(` across every module, and for the method value `.Row` without a call
(none); then every wrapper that forwards a `dst` (`Model.embedToken`, `Model.embedResidentInto`, `Model.gemma4PLEInputs`,
`Model.OutputEmbeddingRow`, `DFlashDrafter.EmbedDraft`, `resident.loadEmbedRow`, `resident.addLearnedPosTo`, `prodEmbedRow`)
followed to its callers.
