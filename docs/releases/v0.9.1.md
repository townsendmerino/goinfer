# goinfer v0.9.1 — tri-module tag

**Release plumbing only. No code, numerics, or behaviour change from v0.9.0.**

v0.9.0 shipped the two native GPU backends, but the root module still referenced the
`gpu` / `cuda` / `metal` modules by Aug-2 pseudo-versions — so the opt-in backends were not
`go get`-able at a real version. This release closes that requirement cycle: the root now
requires the tagged `gpu/v0.9.0`, `cuda/v0.9.0` and `metal/v0.9.0`.

Practical effect: `go get github.com/townsendmerino/goinfer` resolves all four modules at
released versions, and `-tags cuda` / `-tags metal` builds work from a clean module cache
with nothing pinned by hand.

Nothing else changed. If v0.9.0 works for you, this is a no-op upgrade.
