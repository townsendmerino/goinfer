# v0.25.0 release checklist

Release commit: **`36dbfbaf1`** (main frozen from 2026-11-21; this PR adds records and docs only). Tag date: 2026-11-22, once `gate release v0.25.0` reads no OWED row.
**No tag is created by this PR; cutting and pushing any tag requires Francis's explicit yes.**

Release lead: **faster on the machines people already have, WebGPU in a download, and a more accurate default for mid-sized
models** (the release notes, and `CHANGELOG.md` § v0.25.0, 35 entries).

Every command and rule comes from [`RELEASING.md`](../../RELEASING.md); this page is the concrete list for v0.25.0.

## 1. What goes in

`CHANGELOG.md` § v0.25.0 is the list. The headline items:

- Prebuilt WebGPU binaries for Linux (amd64, arm64) and Windows (amd64), with their own checksums and attestations.
- CPU speed: gpt-oss 20B's chosen experts batched into one W4A8 call (1.64× decode); `Q5_K` and `Q6_K` run native on the CPU
  (aikit v1.78.0's AVX2 kernels, Phi-3 mini 1.10×); min-p sampling on all cores.
- Phi-3 and Phi-4 at `--quant q4k` on the Metal GPU by default.
- The 8-bit output layer is the default for models of 1B parameters and up.
- Serving hardening: the panic guard over background work, GPU out-of-memory told apart from bugs, hostile config and image
  limits, `--max-file-store-bytes` (1 GiB default), JSON Schema `format` enforced.
- Library: `decoder.SetLogger`, typed load errors, `Options.RequireBackend`, `Generation.ResidentDeclined`,
  `chat.Template.StopIDs` / `ToolGrammar`, `Model.Shape`.
