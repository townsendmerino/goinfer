# goinfer v0.24.0: more models on the GPU, more conversations in the same memory

This is the biggest goinfer release yet. More model families run fully on the GPU, one card serves more conversations at once, and almost everything got faster along the way.

## More models, on the GPU

- **DeepSeek-V2 and V3 run resident on Metal**, with multi-head latent attention on the GPU.
- **Nemotron-H on CUDA and Metal.** The whole 9B runs on an 8 GB card at 47 tokens/second.
- **Gemma 2 on Metal and CUDA.**
- **Olmo 3, Olmo Hybrid and SmolLM3 on WebGPU.**
- **Q5_K and Q6_K run natively** on Metal and CUDA instead of being widened to int8. Note that outputs change slightly as a result.
- **Gemma 4 E-models are 981 MB smaller on Metal,** thanks to a 4-bit per-layer embedding sidecar.

## More conversations in the same memory

- **Paged KV on CUDA and Metal.** One long conversation can borrow idle memory from the pool: 2.71× the context of a single conversation on Qwen2.5-7B with an 8 GB card. Outputs are bit-identical to before.
- **Prefix sharing is on by default.** Conversations that start the same way, like agents with the same system prompt, reuse each other's work instead of recomputing it.
- **Hybrid models hold two conversations at once on CUDA,** where before each one evicted the other's state on every turn.
- **Host KV snapshots** (`--kv-host-bytes`) keep long prefixes in system RAM, so a returning conversation restores them instead of recomputing.

## Faster

- **Batched decode is on by default in `serve`:** 1.58× for Qwen3.5 and Nemotron hybrids, 1.38× for Gemma 4, and 1.49× for MoE models when two or more clients are talking at once.
- **Speculative decoding on Qwen3.5 hybrids on CUDA:** 1.61× on Qwen3.5-4B, with identical greedy output.
- **Tokenizing is about twice as fast,** 1.79–1.98× with 25–44× fewer allocations, and the token ids are identical.
- **q4k prefill on Metal is 1.99× faster** on Phi-3 mini.
- **Long prompts stay on the fast path:** Gemma 4 past 4,096 tokens on Metal (about 4× faster than before), and several families past 12,000 tokens on CUDA.
- **Loading a 7B on CUDA takes 0.1 GiB of host memory instead of about 4 GiB.**

## Built for agents

- **Tool calls stay constrained with real agent tool lists.** Opencode's 19 tools now cost milliseconds per call instead of half a second.
- **`tool_choice: required` is enforced,** `logit_bias` works, and every response carries per-turn timings.
- **Exact token carry** (`--carry-ids`): agent turns that echo earlier output reuse the exact generated tokens.
- **`/v1/messages` reports cached tokens the way Anthropic's API does,** which Claude Code reads directly.

## Fewer surprises

- **The memory check is accurate on every backend.** It prices what each backend actually allocates, and on macOS it stops refusing models that would fit.
- **An explicit `--kv` precision is delivered or refused with a reason.** It's never silently swapped.
- **`pull` checks disk space before downloading.**
- **Omitted sampling settings use the model's own recommended values** instead of temperature 1.0.

## Verified downloads

Every release file now carries a GitHub build attestation. To confirm a binary came from this repo's release workflow, run `gh attestation verify goinfer-serve --repo townsendmerino/goinfer`.

## Breaking: new import paths

The GPU backends moved under `backend/`:
- `github.com/townsendmerino/goinfer/backend/cuda`
- `.../backend/metal`
- `.../backend/webgpu`, where the package is now named `webgpu`

Update your imports and `go.mod`. Binaries installed through `go install` move the same way.
