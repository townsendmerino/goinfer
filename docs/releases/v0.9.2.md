# goinfer v0.9.2 — documentation corrections

**Docs only. No code, `go.mod`, or numerics change from v0.9.1.**

Three corrections, all to claims that were overstated or measured before a change landed:

- **README benchmark figures.** The 1.5B / 2048-context row predated split-KV attention and
  understated the result (~133 tok/s / 0.71× → **160.1 tok/s / 0.86×**). The table now carries
  the full four-depth curve (128 / 512 / 2048 / 3900) and states the decode crossover at
  roughly 1000 tokens of context.
- **The feature taxonomy** now says a backend *declines* an architecture it cannot fully run,
  rather than claiming wrong output is "structurally impossible".
- **The CUDA speed claim** is stated against the measured curve rather than a single figure.

No behaviour change. Upgrade only if you want the corrected documentation.
