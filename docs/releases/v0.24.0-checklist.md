### Decisions recorded for v0.24.0

- **KV5 cost accepted (Francis, 2026-11-03 14:22 and 2026-11-04 07:32):** keep Metal paged KV (`KV5`) in v0.24.0. It is bit-identical across all 29 gated families, within 1% on the 1.5B and 7B, and about 3–4% slower on `gemma3-1b` at depth 2,048 (`0.975` / `0.970×`) and depth 3,900 (`0.963` / `0.956×`) (`docs/measurements/kv5-metal-2026-11/kv5-2.log`). KV5-3 (giving back the capacity win toward a 32K default context) is deferred to v0.25.0.
- **Gemma 3 split attention kernel kept (Francis, 2026-11-03 15:30, option a):** keep the split attention prefill kernel (`KS-D1`) on Gemma 3 on Metal and state the 91.7% top-1 agreement over 96 positions against the CPU (`94.8%` on the exact kernel it replaces) in the release notes (`docs/measurements/ks-night-2026-10/README.md`).
- **Metal step flags `--gemma4-step` and `--recurrent-step` on in `serve` (Francis, 2026-11-04 09:00, option a: both ON in `serve` when `--kv-sessions >= 2`, OFF in `chat`):** **pending `#666`**. The default change is not yet in the tree (`internal/app/loadflags/loadflags.go` still registers both as `false`); do not state it as done until `#666` merges and its changelog fragment is updated.
- **E1 (`aikit` `v0.30.0`):** n/a here (`goinfer` requires `aikit v1.76.0` across all modules).

**Out of v0.24.0, deferred to v0.25.0** (`docs/releases/v0.25.0-plan.md`):
- **KV:** KV7 host demotion default-on (remains experimental and opt-in via `--kv-host-bytes <size>` in v0.24.0), KV8 per-slot checkpoint restore across multiple slots, and KV5-3 capacity give-back on Metal.
- **Forward architecture & memory:** OP1 softcapping declared in the program tables and WebGPU port, OP6 Phi fast paths, RF0/RF1 ragged forward, D8b-cuda, MEM6-CUDA, MEM11-bf16-CUDA, MEM13 host copies on CUDA, and MEM17.
- **Layout Tier 3:** splitting `decoder/` into subpackages (`arch/`, `fit/`, etc.).

## 5. The two-step tag (from `RELEASING.md`, exact commands)

Run **only after** `go run ./cmd/gate release v0.24.0` exits 0 on `main` and Francis has given an explicit yes.

### Step 1 — root tag

```sh
V=v0.24.0
gh auth switch --user townsendmerino

# Confirm the root requires none of the submodules and no module has a replace:
grep -E "goinfer/(backend/(cuda|webgpu|metal)|cuda|gpu|metal)" go.mod   # must print nothing
grep -n replace go.mod */go.mod */*/go.mod                              # must print nothing
for m in . backend/webgpu backend/cuda backend/metal demo/agent; do
    printf '%-16s ' "$m"; grep -h aikit "$m/go.mod" | tr '\n' ' '; echo
done

git tag $V
git push origin main $V
```

Wait ~30 s for `proxy.golang.org` to serve `github.com/townsendmerino/goinfer@v0.24.0` (or pass `GOPROXY=direct`).

### Step 2 — submodule bumps and tags

`backend/webgpu`, `backend/cuda`, and `backend/metal` first, then `demo/agent` last (it requires `goinfer/backend/webgpu`, so `backend/webgpu/v0.24.0` must be on the proxy before `demo/agent` runs `go get`):

```sh
V=v0.24.0
for mod in backend/webgpu backend/cuda backend/metal; do
    (cd "$mod" && GOWORK=off go get github.com/townsendmerino/goinfer@$V && GOWORK=off go mod tidy)
done
GOWORK=off go build -C backend/webgpu -tags gpu ./...
GOWORK=off go build -C backend/cuda   -tags cuda ./...
GOWORK=off go build -C backend/metal  ./...              # on macOS; prints "matched no packages" on Linux

git add backend/webgpu/go.mod backend/webgpu/go.sum \
        backend/cuda/go.mod   backend/cuda/go.sum \
        backend/metal/go.mod  backend/metal/go.sum
git commit -m "release: backend/{webgpu,cuda,metal} require goinfer $V"
git tag backend/cuda/$V
git tag backend/webgpu/$V
git tag backend/metal/$V
git push origin main backend/cuda/$V backend/webgpu/$V backend/metal/$V

# Now demo/agent (requires both root and goinfer/backend/webgpu, replacing the old goinfer/gpu v0.23.0 require):
(cd demo/agent && \
    GOWORK=off go get github.com/townsendmerino/goinfer@$V \
                      github.com/townsendmerino/goinfer/backend/webgpu@$V && \
    GOWORK=off go mod tidy && \
    GOWORK=off go build ./...)
git add demo/agent/go.mod demo/agent/go.sum
git commit -m "release: demo/agent requires goinfer + goinfer/backend/webgpu $V"
git tag demo/agent/$V
git push origin main demo/agent/$V
```
